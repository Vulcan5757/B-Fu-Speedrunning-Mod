This is an automatic in game timer for speedrunning Boomerang Fu. It auto starts and stops the timer based on the timing for the game's speedrun.com page. It's quite accurate but can sometimes be a couple of frames off. 

It also comes with a fast reset built into it. Press + on controller to quick reset to the character select screen. 
The fast reset will detect when you are doing an any% run and instead of resetting to the character select screen, it'll reset to an any% win screen from that session, allowing for you to hit REMATCH. (Note that you must complete a full any% run before the any% reset will take place)

This mod requires BepInEx installed for it to work: [Guide](https://docs.bepinex.dev/articles/user_guide/installation/index.html)

To install, download Speedrunning Mod.dll file and put it into C:/Program Files (x86)/Steam/steamapps/common/Boomerang Fu/BepInEx/plugins. When you want to disable the mod, change the .dll to .disabled.
