This is an automatic in game timer for speedrunning Boomerang Fu. It's quite accurate but can sometimes be 1-2 frames off. 
It also comes with a fast reset built into it. Press + on controller to quick reset to the character select screen. 

This mod requires BepInEx installed for it to work: [Guide](https://docs.bepinex.dev/articles/user_guide/installation/index.html)
To install, download the .dll file and put it into C:/Program Files (x86)/Steam/steamapps/common/Boomerang Fu/BepInEx/plugins. When you want to disable the mod, change the .dll to .disabled
