This is an automatic in game timer for speedrunning Boomerang Fu. It auto starts and stops the timer based on the timing for the game's speedrun.com page. It's quite accurate but is sometimes a couple of frames off. 

It also comes with a fast reset built into it. Press + on controller to quick reset to the character select screen. 
The fast reset will detect when you are doing an any% run and instead of resetting to the character select screen, it'll reset to an any% win screen from that session, allowing for you to hit REMATCH. (Note that you must complete a full any% run that session before the any% reset will take place)

This mod requires BepInEx installed for it to work: [Guide](https://docs.bepinex.dev/articles/user_guide/installation/index.html)

To install the mod, download the latest release [here](https://github.com/Vulcan5757/B-Fu-Speedrunning-Mod/releases), extract the folder, and put the folder into C:/Program Files (x86)/Steam/steamapps/common/Boomerang Fu/BepInEx/plugins.

To quickly toggle the mod, it's recommended to have the [B-Fu Mod Manager](https://github.com/Vulcan5757/B-Fu-Mod-Manager) installed. Speedrunning mod automatically comes with an in game description & preview for the mod manager.
